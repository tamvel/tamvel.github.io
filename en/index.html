GS1 ScanVortex

A barcode is not a string of digits here. It is a set of business fields.

A GS1 barcode scanner and analyser. It reads GS1-128, GS1 DataMatrix and GS1 QR, splits the payload into application identifiers, checks the structure and the values, and shows the result as readable fields: GTIN, expiry date, batch number, serial number. Everything is computed on the device.

GS1 ScanVortex is the product name. On Google Play the application is available as GS1 Scanner & Generator.

Features

From a scanned code to usable data

The value of this application is not the scan itself, but what happens next: interpreting the payload according to the GS1 standard.

GS1 scanner

Camera scanning in single and batch mode, an aiming frame that narrows detection to the centre of the view, torch, zoom and tap-to-focus.

Over 200 application identifiers

A registry of application identifiers with field names and formatting for dates, ISO 3166-1 country codes and ISO 4217 currencies.

Three layers of validation

Structure, semantics and business rules. The message says what exactly is wrong — with numbers, for example the received and the expected check digit.

Code generator

Creates GS1-128 and GS1 DataMatrix codes. A field wizard with quick-start sets, a date picker, a country list and check digit assistance.

History and CSV export

Every scan lands in the history with a preview split into fields. CSV export builds columns from the identifiers actually present in the data.

Check digit calculator

MOD-10 for GTIN, SSCC, GLN and GSIN numbers — the same algorithm the validation uses, so the suggestion can never disagree with the verdict.

GS1 Digital Link

A GS1 Digital Link URL is converted into an identifier string and analysed exactly like a code scanned from a package.

Photo and clipboard

A code can be read from a photo in the gallery, or a string copied to the clipboard can be analysed — without reaching for the camera.

Works locally

Scanning, validation and generation all run on the device. The history stays in the phone's storage and is never sent to the author's servers.

GS1 standard

Why an ordinary scanner is not enough

A GS1 code does not carry a single value. It carries several fields joined into one string, separated by a character you cannot see on screen. Only splitting them turns a scan into information.

Recognition

A GS1 code is recognised by the AIM prefix the reader adds to the scan and by the FNC1 character in the data. A plain EAN-13 is never treated as GS1.

Splitting into fields

The string is divided into application identifiers and their values, respecting fixed-length and variable-length fields and their separators.

Checking

Every field is checked for data type, length, check digit, date validity and dependency rules between fields. The result gets one of three states.

An honest note on scope: GS1 ScanVortex is a tool for reading, analysing and generating codes. It is not a print quality verifier, it does not certify conformance with the standard and it does not replace measuring equipment.
